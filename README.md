## 逻辑 Skill：logic

按逻辑判别是非：先抽出论证的形式，再依明文的规律判定推论对错，最后用"形式相同、前题真而结论假"的反例说明。

**覆盖**：真假与对错、推论与推理、蕴涵与离断原则；选取推论（相容/穷尽）、条件推论（充足/必须条件）、二难式及其破法；A/E/I/O 与词端普及、类演算与范恩图、位换质换、对待关系（三种存在意含读法）；三段式规律与四格、堆垛式、省略式；关系的九种性质；思想三律、语意界说、分类归类、诡论；穆勒五法、假设与求证；型式、语意、不相干三类谬误；对话体教法、练习题库与书目。

**附带脚本**（仅用 Python 标准库）：

- `scripts/categorical.py`：三段式规律逐条检验 + 范恩区域穷举（现代/AE/传统三种读法），无效时给出反例模型；位换、质换、换质位；对待关系推论表。
- `scripts/truth_table.py`：真值表、恒真式、等值、前题能否推出结论（支持中文变量）。
- `scripts/relations.py`：关系的界域、逆界域、范限、反逆与九种性质判别。

**修正与补充（Skill 中均已标明）**：

1. 修正：三段式的其余规律都可由五条规律推出，但五条放过了 AAO-4（凡H是M，凡M是G ∴有些G不是H）；须补"两前题皆肯定，结论不得否定"。补上后，规律检验与语义穷举完全一致（传统读法 24 式、现代读法 15 式）。
2. 补充：现代（布尔）读法下的对待关系，以及日常说法（"只有……才……"等）到符号的翻译表。

### 安装

- **Claude Code**：把 `Logic` 复制到 `~/.claude/skills/`（个人）或项目的 `.claude/skills/`。
- **Claude.ai**：在设置中的 Skills 页面上传 `logic.skill`。

### 用法示例

- "凡是成功的创业者都很勤奋，小王很勤奋，所以小王将来能成功——这话哪里不对？"
- "如果加息房价就跌；房价跌了，说明加息了。这推理对吗？"
- "用对话体的方式，讲讲为什么 A 式语句不能简单换位。"
- "出 5 道三段式练习题，附答案。"

测试用例见 `evals/evals.json`。
