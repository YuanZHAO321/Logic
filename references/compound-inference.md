# 外部推论：选取推论、条件推论、二难式

这三种都是**外部推论**：只涉及语句与语句之间的关系，不问各语句内部结构（见 categorical.md 开头）。可用 `scripts/truth_table.py` 验证。

## 1. 讨论语言与修辞

- 开始学逻辑，最好从分析日常**讨论语言（discursive language）**着手——集中讨论一个问题所用的语言，其功能在表达确定的真假、是非、对错。抒情语言、情绪语言另是一回事。
- 日常讨论语言中含有逻辑，但并非都合于逻辑，用到逻辑时也很少完备；工作是把其中蕴涵的逻辑"提炼出来，再加精制"（如从鱼肝油制精丸、沙里淘金）。
- **修辞问题对逻辑不重要，甚至不相干**；修辞美丽的语句有时反不合逻辑（"山在虚无缥缈间"："有"不涵蕴在"无"中；"智慧圆润"：以性质形容性质难以思议）。

## 2. 选取推论（disjunctive / alternative inference）

**选取语句**："X 是 Φ 或 X 是 Ψ"。由"或"联系的每一项叫**选项**——可以是语句、名词或表示性质的字眼；数目可以是 2 到 n。

**决定选取推论的两个基本条件**：

- **相容**：两选项可同时承认（隆美尔是德国人 / 号称沙漠之狐；爱因斯坦是数学家 / 物理学家）。**不相容**：不能同真（他正在北极探险 / 正在南极探险）。
- **穷尽**：选项尽举一范围内一切可能或一类中一切分子。"男人和女人"是否穷尽人类？还有中性人，故不穷尽。**逻辑是讲绝对妥当性的，依照逻辑讲话不许失败**；在逻辑上，少数分子影响推论的力量与多数分子完完全全相等（equally powerful）。

**四种配列**（以名词或性质为例）：

| 配列 | 例 |
|---|---|
| 相容而穷尽 | 全类 与 讨论界域（实际事物中几乎没有） |
| 相容而不穷尽 | 生物 与 动物 |
| 不相容而穷尽 | a 与 非a；p 与 非p（只有逻辑数学里才有一刀两断的） |
| 不相容而不穷尽 | 阴 与 阳（还有中性）；积极 与 消极；美 与 丑 |

**推论规律**（前题："X是Φ 或 X是Ψ"）

| 配列 | 肯定其一（X是Φ） | 否定其一（X不是Φ） |
|---|---|---|
| ① 相容而穷尽 | 不定（∴X是Ψ或不是Ψ） | **∴X是Ψ** |
| ② 相容而不穷尽 | 不定 | 不定 —— 无结论可得 |
| ③ 不相容而穷尽 | **∴X不是Ψ** | **∴X是Ψ** |
| ④ 不相容而不穷尽 | **∴X不是Ψ** | 不定 |

一句话记：**否定其一能肯定另一，靠的是穷尽；肯定其一能否定另一，靠的是不相容。** 第③种可推论性（inferability）最强，第②种最弱。

例：
- ①b：游山时远远看见寺院旁站着一个穿法衣的人，不是尼姑就一定是和尚。
- ①a：X 是有颜色的或是蓝的；有颜色时不能断定是否为蓝。
- ②b：警察只抓到甲、乙两个嫌疑人，还逃掉一些；甲说"我不是贼"，不能推出一定是乙。
- ④：不能由"某人不积极"推出"他就是消极"；不能由"你不信唯物论"推出"你就是唯心论"。

**"结子"**：心理、习惯、风俗、传统、权威形成一些结子，使人把只是不相容的东西当作穷尽的："非杨即墨"、"非左即右"、"非前进即落伍"、"不服从就是反对"、"不是某主义便是某主义"、把人只分成两种……"许多人的想法，一套进去，便出不来。"

**分际**：决定哪些名词是否相容、是否穷尽，**不是逻辑的事**（是概念解析或经验之事）；逻辑只提出这些**形式条件**。名词安排进四种条件之一以后，逻辑才告诉我们此"或"有什么运算能力。**逻辑型式的陈示必须是显明的（explicit）**。

**与真值函数的对应（补充）**：命题逻辑中 `p∨q` 是相容的或，本身就表示"穷尽"（二者至少一真）；"不相容"须另写 `~(p·q)`；"不相容而穷尽"即 `p⊻q`。故在形式化时，把相容/穷尽当作额外前题明白写出：
- `p∨q, ~p ∴ q` 有效；`p∨q, p ∴ ~q` 无效；加上 `~(p·q)` 后有效。

## 3. 条件推论

**条件语句**（旧称假定语句 hypothetical sentence）："如果某人嗜吸鸦片烟，那么某人便面黄肌瘦"。
- 在英文文法上是虚拟法，在逻辑上是**直叙语句的一种**，照样有所断定；它断说的不是两子句各自为真，而是**子句之间的真假关联**。
- 记作 `p⊃q`。p 叫**前件（antecedent）**，q 叫**后件（consequent）**。
- **逻辑的正身根本不过问因果关联**；因果关联只是对 `p⊃q` 的种种经验**解释（interpretation）**之一。对逻辑形式套上一组表示经验内容的语句，叫该形式之解释。

**真值与真值表**：每一语句非真即假；`~p` 表示 p 假。n 个语句的真假可能排列有 2ⁿ 种（美与健四种排列：既美且健、美而不健、不美而健、既不美也不健）。

| p | q | p⊃q |
|---|---|---|
| T | T | T |
| T | F | **F** |
| F | T | T |
| F | F | T |

- 只有"前件真而后件假"时 p⊃q 才假。第三行如"如果太阳从西边出来，那么天文学家修正其学说"；第四行如"如果恐龙现在飞得起来，那么现在天昏地暗"。
- 这是比较宽泛的蕴涵（实质蕴涵），为数学的精确推理与严格科学语言所不可少；哈佛的 Lewis 认为 p 假而 q 真不可能，另建**严格蕴涵系统**。"习惯与否，并非真假与否的标准。"

**三种条件**（传统解释）——前件对后件是充足条件，或充足而又必须的条件；后件对前件是必须条件：

| 条件 | 界说 | 墨子 | 例 |
|---|---|---|---|
| **充足条件** | 有X则有Y；无X则有Y或无Y | — | 出太阳 → 看得见（有月亮、电灯也看得见）；下雨 → 地湿 |
| **必须条件** | 有X则有Y或无Y；无X则无Y | 小故："有之不必然，无之必不然" | 有颜色 之于 紫色；经济条件 之于 美好生活 |
| **充足而又必须** | 有X则有Y；无X则无Y | 大故："有之必然，无之必不然" | 二氢一氧化合 之于 成水；日光 之于 叶绿素 |

- 把经济条件这一**必须条件**当作美好生活之**充足而必须**的条件，是长期宣传造成的错误。
- 自然科学所求多为充足而又必须的条件；社会人文现象中条件相互交织，常互为充足或必须条件，故社会科学远不及自然科学精确。有人说在社会现象里发现了解决整个人类问题的唯一真理，须以极谨慎的态度考虑。
- **三种条件只是型定方式（formulations）**：把某现象当作何种条件，视情境的需要或研究程序的便利而定（玫瑰与磷肥：其他条件俱备时磷肥是开花的充足条件，缺水时就不是）。但"不可胶执"不等于"随随便便"；一旦决定了什么是什么条件，据之推理时必须依照逻辑规律。

**推论规律**（前件为后件的充足条件，后件为前件的必须条件）：

| | 可否推论 |
|---|---|
| 1. 肯定前件 | **可以肯定后件**（温度增高 → 物体膨胀） |
| 2. 否定前件 | 不可推论后件真或假（"如果某人被杀，那么他死了"，不能接着说"未被杀则不死"） |
| 3. 肯定后件 | 不可推论前件真或假（地湿了，不能推出下了雨——洒水车也会洒湿） |
| 4. 否定后件 | **可以否定前件**（连生物都不是，更说不上是动物） |

**前件真时有肯定的推论力；后件假时有否定的推论力；前件假、后件真都没有推论力。**

- 有些特例中否定前件"碰巧"可以否定后件（平均九十分才得奖学金），但逻辑所说的永远是普遍的 p 与 q，必须有**普遍妥当性**（对每一情形都真），所以一概不从否定前件作推论，便永远不会错。
- "墨子出于印度"论文：如果X是印度人则X是黑的；墨子是"墨（黑）"的；所以墨子是印度人——肯定后件的错误。
- **若前件是充足而又必须的条件**，推论规律对称：前件真则后件真，前件假则后件假，后件真则前件真，后件假则前件假。
- 所以先要确定前件究竟是充足条件还是充足而必须的条件——**这一决定不是逻辑的事**；决定之后运用推论规律，才走进逻辑范围。
- "年轻人就喜欢**简单的确定**（simple certainty），害人不浅！"不能确定的就还他一个不能确定。**逻辑之为学，从一方面看，就是严格划分哪些是可以确定的、哪些是不能确定的之学。**

## 4. 二难式（dilemma）

古希腊辩士所创，如猎人设陷阱，使对方无论赞成或反对哪一端都无以自拔。"如果你结婚，便有家室之累；不结婚，便孤独苦闷；你只有结婚或不结婚，所以……"

**四种基本形式**

| 形式 | 结构 | 例 |
|---|---|---|
| 简单肯定前件 | 如甲则丙；如乙则丙；甲或乙 ∴丙 | 天热人难受，天冷人也难受；天气只有热或冷 ∴人总是难受 |
| 简单否定后件 | 如甲则乙；如甲则丙；非乙或非丙 ∴非甲 | 统治世界须有超级原子弹，又须使人心悦诚服；二者皆不能 ∴不能统治世界。芝诺：物体在所在之点动或在所不在之点动…… |
| 复合肯定前件 | 如甲则乙；如丙则丁；甲或丙 ∴乙或丁 | 学而不思则罔，思而不学则殆；《孟子》周公知而使之是不仁，不知而使之是不智 |
| 复合否定后件 | 如甲则乙；如丙则丁；非乙或非丁 ∴非甲或非丙 | 聪明则知己错，诚实则认己错；他不知或不认 ∴不聪明或不诚实 |

- **从逻辑观点看，二难式根本是多余的**：它是条件推论与选取推论复合而成，最后可化约为选取推论；所以必须同时遵守这两种推论的规律。选项不限于二，可有 n 难。**所谓"难"是心理状态，在逻辑上没有难不难的问题。**

**三种破法**
1. **否认前件为后件的充足条件**（"结婚未必有家室之累"）。
2. **否认选取语句互不相容或共同穷尽**（指出还有第三种可能）。
3. **作一个结论与之相反的二难式**："如果我结婚，可有伴侣之乐；不结婚，可免家室之累……"

**半费之讼**：勃洛泰哥拉斯（Protagoras）与学生伊纳塞拉斯（Euathlus）约定第一次打赢官司付清另一半学费。师："胜诉依合同须付，败诉依判决须付"；生："胜诉依判决不付，败诉依合同不付"。
- 解析：有两种条件——法庭判决（①胜诉不付 ②败诉须付）与合同（③胜诉须付 ④败诉不付）。老师取②③，学生取①④，各把有利于己的条件拉到自己一边，不利的扔在一旁，**各说各的，彼此并未碰头（never meet）**。"可见解析之重要。"

## 5. 把日常说法翻成形式（补充，非条文）

| 日常说法 | 形式 | 说明 |
|---|---|---|
| 如果p，那么q；p 则 q；一旦p就q | p⊃q | p 是 q 的充足条件 |
| 只有p，才q；除非p，否则不q | q⊃p | p 是 q 的必须条件（"小故"） |
| 当且仅当p，才q；p 则 q，非 p 则非 q | p≡q | 充足而又必须（"大故"） |
| 或p或q（可兼） | p∨q | 只保证穷尽 |
| 要么p要么q，不可得兼 | p⊻q | 不相容而穷尽 |
| 不能既p又q | ~(p·q) | 只保证不相容 |

日常语言中的"如果……就……"常被说话者当作"当且仅当"使用；分析时先问清（或在报告中写明）采用哪一种读法，再引用相应规律。
