## 1. 逻辑的范围

- 现代逻辑包含：①语句联系论；②函量论；③集合论。
- **作者的看法**：因明学多少有些逻辑成分，但与其说它是逻辑，不如说是佛学方法论，是宗教思想的副产品；若一定叫它逻辑也有命名之自由，但不可与衍发于亚里士多德的逻辑混为一谈（"甲营的张得标一定不是乙营的张得标"）。把历史上叫做逻辑的知识论、形上学成分都留在"逻辑"名下，是无视半个世纪以来逻辑的进展；这样的"太狭"，就学问谨严说倒是必要的。

## 2. 思想三律

传统说法：**同一律** A是A；**矛盾律** A是B 与 A不是B 不能同真；**排中律** A是B 或 A不是B。

**重要与否是相对的**：相对于某系统构造，可能被放在始基语句（primitive sentences）之地位；在 *Principia Mathematica* 中三者根本不放在始基地位，只是被推出的语句；Hilbert–Ackermann、Quine、Lewis 及波兰逻辑家的系统也都不以之为始基。原因：它们在记号结构上不够丰富，缺乏衍生力量。

**陈示本身有歧义**：是关于事物的规律，还是关于语言层面（linguistic level）的规律？若是关于事物的，"A是A"简直一点意思也没有。

### 同一律：一个语意原则
- **对"静的逻辑/动的逻辑"之说的批评**：朴素的人把"毛虫是毛虫"解作"肯定毛虫不能变成蝴蝶"，于是说传统逻辑是"静的逻辑"，须有"A是A又不是A"的"动的逻辑"。这是搅混之谈、文字魔术。古今说"A是A"的逻辑家，"如非大愚，宁不知事物时时变动之此一浅显常识？"
- "A是A"中，A 是变量，"是"有好几种意谓，变量的级距（range）不定，所以整个式子含混。
- **同一概念的三种可能**：
  ```
  ① 张江陵 = 张江陵   真，但琐细不足道
  ② 张江陵 = 张巡     假，须消去
  ③ 张江陵 = 张居正   既真又有用：联系两个不同的名，所指为同一对象
  ```
  包含同一概念的语句，包含两个指谓同一事物的**不同**名词，因不同才有用。仅研究语言不足以决定二名所指是否同一，还须研究历史事实。
- **名与所指之别**：可以说张居正为人严苛，不能说"张居正"这个名字严苛；"张居正"这名字由三个字联缀而成，张居正这个人却不是。形容一名的形容词不能用来形容名之所指，反之亦然——许多日常语言与传统哲学的混乱起于不明此别。
- **现代的解释**：同一律是一**语意原则（semantical principle）**——在一所设意义系络（context）之中，同一文字或符号在各处出现，**必须有一固定的意谓或指涉**。没有这个条件，语言只是一堆声音。"如如""道可道非常道"中前后两字所指不同。
- 同一律完全是说话用字方面的问题，与事物之变或不变、世界之动或静毫不相干；它既没有否认变之可能，也没有承认变之可能（那是形上学分内之事）。少年就说少年，老年就说老年。"柏拉图是个人又不是个人"——多别扭。
- **赫拉克利图斯的河流**：关键不在同一概念，而在事物与时间概念。事物是散在空间、延伸于时间的**微粒瞬间（particle-moments）**之和；水分子已不同，河还是嘉陵江。**事物有变化，名只有更换**，好比因早晚不同而更换衣服。

### 矛盾律：一个语法原则
- **事物只有相反，根本没有逻辑矛盾**。逻辑矛盾须同时满足：X 与 Y **共同穷尽**且**互相排斥**；事物界没有同时满足这两个条件的，充其量只有相反（生与死、善与恶）。
- 矛盾律：从一个包含一组公设的逻辑原理中，得不到 A 与 ~A 二者；即不可承认两个互相矛盾的**表示（expressions）**可以同真。所涉者是语法规律，不是事物规律。

### 排中律：一个语意原则
- 排中律**不排事物之中**：不是说事物只有阴与阳而没有中性。
- 它说：指与所指之间必须有所指定——一个文字或符号要么指谓 X，要么不指谓，不可既指谓又不指谓。是固定指涉的另一方式。
- 数学直观派（Brouwer）不赞成排中律——那是很专门的范围。

**结论**：三大思想律并非"思想律"（理由同逻辑非思想之学）；它们是**语意或语法之最低限度的必须条件**，违反了就无语言意谓可言，或得出互相矛盾的结论。

## 3. 语意界说

**用途**：科学书开头的界说；订条约、谈判时的名词界说；讨论中发现彼此用同一名词而格格不入时，应**中止主题讨论，对所用名词复位界说**——即使意见不同，也可弄清不同之点究竟何在。

**界说的普遍型式**：
```
—— =Df ……
被界定端（definiendum）   在界说上相等   界定端（definiens）
例：潜水艇 =Df 在水中航行的机动船只
```
- **界说所介绍、所界定的是名词（或符号），不是事物本身**。一物可有二名；我们可以建造或击沉一艘潜水艇，但不能"界定"其本身。
- 罗宾森（R. Robinson）*Definition* 一书列界说十九种之多。

**基本三种**：
1. **语法界说**（名目界说 nominal definition）：纯为介绍新名词、新记号，不涉意义。`n! =Df 1×2×3……(n-1)×n`
2. **语意界说**（semantical definition）：界定端陈示被界定端的意义。"逻辑是必然有效的推论之科学。"
3. **实质界说**（real definition）：陈示被界定端的"实质"。"怯懦是借行较小的恶以避免较大可怖事物。"——"实质"意义不易确定，科学与日常很少用，只有本质论者感兴趣，不取。

**定立语意界说的五个理由**：
1. **移除歧义**（及由此引起的混乱）。钞票之辩：甲说钞票"脏"指"金钱万恶"一类的**价值判断**，乙说"新印的不脏"指"衣服污秽"一类的**事实判断**——同用一字，各说各的，没有碰头。像织毛衣时绳头纠结要马上解开。
2. **调节意义范围**：太宽的收窄（"哲学"），太狭的放宽（"民主"不只指一种政治制度，也指一种态度或生活方式）；常识中的"能力""热"富于意象情感，物理学必须重新界定；心理学的"智能""本能"亦然。
3. **增进新意义**：新事物、新名词（"熵"；"航空母舰是作为航空基地的舰只"）。
4. **保证推理之一致**：只有从无歧义的、精确的名词出发，才可作无误的推理。
5. **简缩语言**：语言经济，且易于把握中心意义（以"抗战"界定"对日本军国主义者之侵略从事抵抗战争"）。

**定立的四种门道**（严格说没有普遍程序）：
1. **同义词**：闭户即关门；犬即狗。传统规律禁止界定端含同义词，"夫军阀者，军中之阀也"固然无用，但以对方熟悉的同义词界定其不熟悉的名词，目的就达到了。
2. **解析法**：用成语厘清（"哲学者，爱智之学也"）；亚里士多德的种（genus）、属（species）、别（differentia）："人是能用工具的动物"。只能界定普遍或抽象名词，不能界定"罗米欧""嫦娥"。
3. **综合法**：把名词置于一个关系系统中的某一地位（"红"=正常人眼受波长 7000–6500Å 刺激时所生之颜色；"圆"=封闭曲线上任何点与其内一定点距离相等之图形）。
4. **指明法**：展示外范中的分子（"洋"者，太平洋、大西洋、印度洋、南冰洋、北冰洋）。

**九条规戒**（传统界说规律已站不大住，界说之创建颇有艺术成分；但从经验可得规戒）：
1. 不必要时不定界说，不要改变大家已接受的界说（破坏约定俗成，增加脑力负担）。
2. 除非有充分理由证明原有名词太繁重，否则不用界说；原有语句够用不必另造新名。
3. 无名以名所须名之事物时才立界说；若在专门学问范围以内，请教该门专家，切勿自作聪明（弄玄学的人自订物理名词界说，难免贻笑大方）。
4. **不可以一名而界定两次**（Cohen 与 Nagel 把"独立"界定成两个意义）。
5. **不可把界说当作回避**：讲到半途发现不通，就从名词上找出路、歪曲原义——不真诚（not sincere）。
6. **界定端须与被界定端切合（范围大小相等）**：柏拉图派"人是没有羽毛的两足动物"太宽（阿基思拿出刚孵出的小鸡）；"人是识字的动物"太狭。
7. 能用肯定语气时不用否定语气（"男人是不是女人的人"）。
8. 界定端不可用意谓暧昧的表词——否则"以其糊涂还其糊涂"。
9. **界说不可循环**：被界定端不可出现于界定端（"人者人也"）。例外：递归界说（recursive definition）。

## 4. 分类与归类

**分类（classification / division）**：把一个类分为次类（sub-class）。逻辑不研究分类的应用（图书编目、家谱、界门纲目科），只研究其原理原则。

普遍构架——**二分法（dichotomy）**：X 分为 X1 与 -X1（补类），X1 再分为 X1a 与 -X1a……一直到无可再分或不必再分。二分法曾被视作分类最基本的程序。

**规律**：
1. **分别层次**：起点（最高层次）与终点（最低层次）是相对的，视需要而定；但**同一层次的事物必须与同一层次的事物并列**，否则层次紊乱（把光学、声学与物理学并列；把细胞学与生物学并列）。
2. **所分之类必须互不相容**（把"物"分作"生物"与"动物"等于没有分类；医院外用药与内服药摆混会毒死人）。
3. **每次分类只采取一个标准**；同一层次用两个以上标准便成**跨越分类（cross division）**——同时依肤色与高矮，分出"长白种人""矮白种人"……"妙不可言"。
4. **标准之数目须足以穷尽所分对象**，否则有遗漏（哲学书只分两类，第三类无处可编；生物学发现新种须创新格）。

**选择重要的性质作标准**：若以 A 分类，两类除有无 A 外别无不同，此分类无用；若以 C 分类，凡有 C 者皆有 E、凡无 C 者皆无 E，表出同存的性质，此分类有用。以颜色形体分动物会把鲸归鱼、蝙蝠归鸟；以脊椎分则表出齿喙、背神经总管、腹下循环机关等同存因素。选议员以"说话漂亮"为标准不可靠（不诚实也可随说话漂亮而来），以"公正"为标准则诚实、无私可相随而来。

**归类**：依事物的性质或其他共同点把它们集成类，程序与分类相反——从最小的类起，一层一层归到最大类。
- 一般人依需要、利害、兴趣甚至注意力归类，有实用价值而无科学价值：以鲸为鱼，以煤为无机物，以海白头翁为植物；呼吸、燃烧、生锈被当作不同现象，其实都是氧化——凭常识不可想象。
- 归类是"在杂多之中见共同之点"，是科学首先采用的方法；植物学、动物学长期停在归类阶段。
- 《荀子·正名》："推而共之，共则有共，至于无共然后止。"
- 归类的原则与分类相似，变通即可。

## 5. 诡论（paradox）

**自我推翻的说法**（似诡而非真正的诡论）——由肯定其为真，得到其为假，`如果p，那么~p`：
- "一切真理是相对的"：说这话就是肯定它是真的，它就不是相对的了。
- 绝对怀疑论："一切道理都是可以怀疑的"——对这个道理就不怀疑了。
- "这个世界没有真理"。

**真正的诡论**须满足两个条件：⑴由真推出假；⑵由假推出真，`p 等于 ~p`。
- **说谎者**："我是在说谎"。若真则是假话；若假，则说这话是假的，这话就是真的（假假得真）。

**原因**：语言之**自我指涉（self-reference）**。
- 有些形容词指谓自己不出毛病（*homological*）："English is English"、"Polysyllabic is polysyllabic"；有些一指谓自己就出毛病（*heterological*）："Monosyllabic is monosyllabic"；"Long is not long"（long 只有四个字母，short 有五个）——第二个 long 是在**涉谓**第一个 long 字，二者记号设计相同而不在同一层次。
- **语言的使用（use）与语言的涉谓（mention）**：
  ```
  (1) 北平是一个城       —— 说的是名称之所指（designatum）
  (2) 北平有十笔         —— 说的是"北平"这个名称本身（designation）
  ```
  二者判若云泥，混淆便产生诡论。"我在说谎"这动作是第零层次；表达它的语句"我在说谎"是第一层次；说"我在说谎"这个语句是第二层次。用表达层次 i 的语言形式来表达高一层次的语言，叫做**不合法的全指（illegitimate totality）**。
- **类的诡论**：把一切类分成⑴包含自己为分子的类、⑵不包含自己的类（穷尽的分类）。问：⑵属于⑴还是⑵？若⑵属⑴，则⑵以自己为分子，但⑵的分子都不以自己为分子，故⑵不属⑴；若⑵属⑵，则⑵以自己为分子，应归⑴。结果"⑵是⑵的分子"等于"⑵不是⑵的分子"——恶性循环（vicious circle）。根源在把"类的分子关系"当作自反关系。

**对策**：为了免除自相矛盾，必须**限制"全体"之构造**。用"一切"时特别小心：只能说同一类型的一切事物，或某一层次的语言之一切表式；不能无限制地说"一切语言"——用来说一切语言的语言，一定比所说及的最高层次的语言还高一层次。（罗素的类型论、塔斯基的语言层次即本于此。）

**应用**：遇到"一切观点都是偏见""没有客观标准""任何说法都是相对的"一类全称断言，先问它是否把自己也包括在内；若包括，检查它是否自我推翻。
