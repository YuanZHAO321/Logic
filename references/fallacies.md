## 1. 合理与服人

- 通常以为"合理者可以服人，服人者也一定合理"，其实不然。以 R 表合理的语言，C 表服人的语言，范恩图分三部分：R 而非 C（合理而不服人）、C 而非 R（服人而不合理）、R 且 C。二者至多部分重叠，不能相等——这是人类社会不够愉快的一大原因（希特勒的演讲使广场上的人如痴如狂）。
- 逻辑研究的直接或间接作用，是**扩大既合理又服人的那一部分**。完全符合不可能（求全不遂最易趋于幻灭），但做到一分算一分。

## 2. 合于逻辑、非逻辑、违反逻辑

| | 英文 | 意谓 |
|---|---|---|
| 合于逻辑的 | logical | 合于一切逻辑规律的推论 |
| **非逻辑的** | non-logical（extralogical） | 无关乎逻辑：单独的语句不在任何推论关联之中，像不在轨道中的游离电子，无所谓合不合逻辑——"卵有毛""鸡三足""火不热"（假）与"太阳是发光的"（真）同样是非逻辑的 |
| 违反逻辑的 | illogical | 违反逻辑规律的推论 |

- 一般人以为真话就是"合于逻辑"的、假话就是"不合逻辑"的；其实语句的真假与其是否合于逻辑毫不相干。
- "说话写文章必须合逻辑"之说，意谓多半是"要求正确"。家常话、散文、非理论性的文不必合于逻辑规律（"等于在戏院里要人读经"）；**正式讨论问题、表达理论的文，一定得合于逻辑规律**。
- 研究哲学比研究科学更需要逻辑：经验科学有实验与客观事物限制，纯理论科学有符号与公式限制，哲学几乎没有限制——"如果这是一病的话，那么此病须靠逻辑来医"。

## 3. 型式的谬误（formal fallacy）

严格的逻辑谬误：凡违反有效推论规律的推论。

| 谬误 | 例 | 正确规则 |
|---|---|---|
| **潜越位换** | "北平人说国语" → "说国语的人是北平人"；"一切读书人是有知识的人" → 倒过来说 | A 只可限量位换为 I；O 不可位换 |
| **以 I 推 A**（对待关系误用） | 某人说了我一两句不好的话，便以为他说的全不好；看见一两条街不好，便说那地方简直不好 | I 真则 A 不定 |
| **混淆反对与矛盾** | 以为"一切欧洲人是基督教徒"的矛盾是"没有欧洲人是基督教徒" | A 的矛盾是 O |
| **相容选项：由肯定其一而肯定或否定另一** | "他喜欢吃饭或吃面；他喜欢吃饭，所以不喜欢吃面"；"他是坏人或骗子；他是坏人，所以也是骗子" | 相容时肯定其一，不能肯定或否定另一 |
| **不穷尽选项：否定其一而肯定另一**（假二分） | "你不是唯物论者，那就是唯心论者"；"他不积极，那就是消极"；"X 不是纳粹党徒，所以是天主教徒" | 不穷尽时否定其一，不能肯定另一 |
| **否定前件** | "若经济贫困则人民沦为盗窃" → "经济不贫困则不沦为盗窃" | 否定前件不能否定后件 |
| **肯定后件** | "若善于经营则有钱；他有钱了，所以善于经营"；"若赞成和平则发动和平宣传；他发动和平宣传，所以赞成和平"；"真正民主国家实行竞选；某地有竞选，所以是民主的"——"人世间许许多多欺骗的事，都是利用人们易由肯定后件而肯定前件做出来的" | 肯定后件不能肯定前件 |
| **三段式诸谬误** | 共词不普及、大词/小词潜越、两否定前题、否定前题得肯定结论、两偏谓前题、两肯定前题得否定结论、四名词 | 见 syllogism.md |
| **关系性质误用** | "朋友的朋友是朋友"；"a 是 b 的弟兄，所以 b 是 a 的弟兄" | 准传达/准对称不可当传达/对称 |
| **二难式中的偷换** | 把只有部分条件的二难式当成穷尽（半费之讼各取有利条件） | 检查前件是否充足、选项是否穷尽 |

## 4. 语意的谬误

语意的谬误不都是逻辑谬误，但有一部分与逻辑关系密切。

- **分谓**（division）：对全体为真的话，对部分说了。"某国是好侵略的，某人是某国之一分子，所以某人也是好侵略的"（敌对国家的人民常用这种方法攻击对方）；"美国那样富，斯密司是美国人，难道他没有钱吗？"
- **合谓**（composition）：对部分为真的话，对全体说了。"正方形的每一边是一条直线，所以一个正方形是一条直线。"
- **模棱辞令**（amphiboly / 语意含混）：看相先生说"父在母先亡"——父母双存、俱亡、一存一亡，各有两种情形，共六种，句句说得通。"要不然江湖上哪能骗得到饭吃？"自然语言尤其中文富于意象与附着因素，免除含混要大费气力。
- **歧义（一字多义）**：同一记号设计在同一场合有两种所指（钞票"脏"之辩；"如如"；三段式中的"四名词"）。对治：语意界说、同一律。
- **混淆使用与涉谓**："北平有十笔"说的是名字；混淆层次产生诡论。
- **滥用"必然"**：把逻辑的必然移置于历史、社会现象。

## 5. 不相干的谬误

**相干的形式界定**：有X则有Y，且无X则无Y → 相干；有X则有Y，而无X则有Y或无Y → 不相干。X 与 Y 相干与否大部分决于知识，逻辑不研究一个一个的不相干情形。

| 谬误 | 拉丁名 | 说明与例 |
|---|---|---|
| **滥引权威** | *argumentum ad verecundiam* | 在相当范围内权威应受尊重，范围以外就应受限制。爱因斯坦是物理学的权威，不必是政治权威 |
| **诉诸群众** | *argumentum ad populum* | 某大学以举手表决反对"从无机物造出细菌"——那篇文章确有错（手术不慎把细菌带进试管），但反对的办法太不相干。**意愿问题**（食堂吃饭还是吃面）可以表决；**真假问题**必须取决于试验或推理，与多数是否赞成毫不相干（达尔文进化论遭多数揶揄；特创论受多数赞成） |
| **诉诸暴力** | *argumentum ad baculum* | "说不过就讲打"；巨棒可以使对方接受，却不能证明你的说法是真的 |
| **攻击人身** | *argumentum ad hominem* | 道理说不过，转而攻击对方操守品行；没有养成"人与事分开"之习惯的人最易犯。与诉诸暴力深结不解之缘 |

## 6. 思维的心理障碍与语言陷阱

| 障碍 | 要点 |
|---|---|---|
| 成见、风尚、习俗迷信、利害情感 | 心理情形影响思维；言论之真假与风行与否不相干 |
| 凭经验判断推论对错 | "因为香瓜都不酸"——是在报告经验，不是在讲逻辑 |
| 简单的确定 | 不能确定的事硬要确定 |
| 结子（假二分） | 非杨即墨、非左即右、不服从就是反对 |
| 激动语言冒充真理 | 能激动人的语言不必真 |
| 修辞当作逻辑 | 省略式、双重否定加强语气 |
| 名与所指混淆 | "张居正"这名字由三字组成 |
| 以"动的逻辑"反对同一律 | 混淆事物之变与用名之固定 |
| 自我推翻的全称断言 | "一切真理是相对的" |
| 以前后相承为因果 | 昼夜、晚霞 |
| 把统计用于个人 | 50% 不能毕业 ≠ 张某 50% |
| 比于不伦的类比 | 天无二日，民无二皇 |
| 无法印证亦无法否证的假设 | 入地狱被硫黄火烧 |

## 7. 速查：怎样检验

| 看到这种说法 | 先检查 | 工具 |
|---|---|---|
| "……所以……"，含"凡/有些/没有" | 整理成三段式，查规律 | `categorical.py syllogism` |
| "倒过来说也一样" | 位换规律 | `categorical.py immediate` |
| "不是A就是B" | 选项是否穷尽、是否相容 | `truth_table.py argue` |
| "如果……那么……" + 观察到结果 | 是否肯定后件 / 否定前件 | `truth_table.py argue` |
| 两难困境 | 前件是否充足、选项是否穷尽、能否造反向二难式 | `truth_table.py forms` |
| 同一个词出现多次 | 前后所指是否同一 | 语意界说 |
| "大家都认为""专家说""他人品差" | 是否不相干 | 相干的形式界定 |
| "X 之后发生 Y，所以 X 导致 Y" | 单程相承 ≠ 因果；可否用别异法 | 穆勒五法 |
| "一切……都是……"（包括这句话自己） | 自我指涉 | 诡论 |
