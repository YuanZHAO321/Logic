## 1. 经验科学与演绎科学

- 物理学、地质学、生物学、经济学等**经验科学**大部分依观察、试验、推广建立；其结论多半不是从前题严格推演出来的，而是理论；由理论抽绎的**推广（generalizations）**，充其量是高度盖然的，不是必然的。
- 科学理论或推广通称**假设（hypothesis）**——也是一个语句，依当前证据只有大于 0、小于 1 的盖然程度。
- 早期科学只是记述与归类；归类之中包含**抽象作用**，由此可作推广（"水到摄氏零度便结冰"；牛顿定律是更精确更普遍的推广）。**推广是经验科学的中心**：据以解释自然现象并作预言。
- 共变推广：若 A 出现则 B 出现，且 B 出现则 A 出现，可说 A 与 B 共变；由此可演绎出个例（水加热至一百度在海平面会沸腾）。

## 2. 因果观念

- 世界各地的因果观念不同：轮回（"他前世是猪"）、道德果报（被雷打死是"不孝的报应"）。科学的因果观念：他被雷打死是因为在雷雨中立在导电体下。
- 许多科学家抱持"每个事件有一个原因"的设臆；休谟（Hume）对因果观念提出严格批评；量子物理以后，趋势是**以函数观念代替因果观念**。但日常生活与初步研究中因果观念仍不可少。
- **三个必须弄清的要点**：
  1. 科学的基本兴趣是求**因果律**，不是一个一个的特殊因果事件。
  2. **单程方向的有规律前后相承，不足以确定因果**。否则白天是黑夜的原因（对过夜生活的人，黑夜又是白天的原因）；日落是晚霞之因，早霞是日出之因。有规律的相联可以**假定**有因果关系，不可**肯定**——"'假定'与'肯定'之间的距离是很大的"。
  3. **因果律只是科学推广之一种**。因果只说时间中 A 与 B 相承，且不可复返；许多推广（波义耳定律 pV 与 T）时间顺序根本无关紧要。"鸡生蛋还是蛋生鸡"从因果观点看是傻问题（其中还含语意问题）。
- **因果联锁（causal nexus）**：间接的因果（巴西咖啡歉收 → 美国咖啡涨价；人口繁殖 → 食物不足 → 争夺 → 战乱）可借确定的知识织成联锁，但做这件事要特别当心。

## 3. 穆勒五法（Mill's Five Canons）

| 方法 | 内容 | 例 |
|---|---|---|
| **合同法**（Agreement） | 所研究现象的若干例子只有一种情境共同，则此情境是现象的因或果 | 金属生锈、动物呼吸、木材燃烧，除氧化外无共同点 → 氧化为共有之因 |
| **别异法**（Difference） | 现象在一例出现、另一例不出现，二例只有一个情境不同，则此情境是其因或果或与之有因果关系 | 玻璃罩内闹钟，抽去空气就听不到 → 空气与音响传播有因果关系 |
| **同异联用法**（Joint Method） | 正面一组事例只有一情境相同；反面一组事例都没有该情境、此外别无共同点 → 该情境是因或果或果之不可少部分 | 华勒士（Wallace）解释北极动物颜色：随环境变白的动物以同色自保；不变白的（冰貉居树上同树皮色、貉羊需易于辨识归群、乌鸦食死肉不需避祸）以异色自保 → 保护色说成立，化学反应说不成立 |
| **剩余法**（Residues） | 从现象中减去已知为某些前项之结果的部分，剩余部分是其余前项之结果 | 无谓的礼俗久久不改，生活不必须，剩余的原因是传习力 |
| **共变法**（Concomitant Variation） | 一现象以某方式变化，另一现象随之以某特殊方式变化，则二者有因果关联；须借测量知变化程度 | 水银柱升降与气温；商业循环 |

- **限制**：别异法碰到不能付诸实验的情况便无用武之地。"希特勒能攫取权力是因为凡尔赛条约太苛刻"只是"想当然耳"的假设——无法人为制造一个除和约较宽大外其余极相似的情境。对社会现象中遥远而间接的因果说要格外小心。
- **五法都只有启发作用**，能提供理由，但没有一种能使我们得到确切不移的结论；不可看得过分呆板。
- 应用五法时必须先**判断相干与不相干**。

## 4. 相干

- 相干是很难界定的概念，决定于知识与经验（判定癌症与吸烟是否相干需要医学、生理学知识）。常识、原有知识、原创力、思想上的冒险精神、想象力都不可缺。直觉有时有帮助，"但这要看什么人的直觉"——爱因斯坦在物理学上的直觉碰对的机会多，因为他有五十年的累积。
- **形式的方式**（为研究之便）：
  - 有X则有Y，无X则无Y → X 与 Y **相干**；
  - 有X则有Y，而无X则有Y或无Y → X 与 Y **不相干**。
- 例：夜梦不祥与白天遭殴、流星与拾得银币——碰巧先后出现。珍珠光泽：松脂、黄蜡、铅印上珍珠壳也有同样光泽，而化学成分各不相同 → 光泽与珍珠壳化学成分不相干。

## 5. 类比与统计

- **类比（analogy）**：A 与 B 在某些方面相似，推论 A 在其他重要方面也与 B 相似。只有启发作用，成功程度与知识、训练、想象力相关——要知道哪些类似点重要，哪些毫不相干。比于不伦之例："人之有文武，犹车之有两轮，鸟之有两翼"；"天无二日，民无二皇"。
- **统计**：许多现象找不到齐一的函数关系（也许没有、也许技术不足、也许太复杂），只好用统计对付（气体原子；死亡统计表决定保险费）。
  - **统计结果只可应用于群集，不适用于群集中的个别分子**：某大学 50% 学生不能毕业，不能说张某有 50% 的机会不能毕业。
  - 统计是外部的记录，不能看得太确定；但可给我们因果或趋势方面的启示，促使提出进一步的假设。

## 6. 假设的六项要求

假设是语句，其证明尚未确定；不完全是猜，多少有点根据。若已确知为真，便不复为假设而是定律。提出合用的假设**没有普遍规律可循**，但须满足：

1. **适于说明它所要说明的一切基料**：与解释对象之外范广狭相当。以关于"自然现象"的假设解释"社会现象"，引起**减削的不适当（reductive inadequacy）**。
2. **结论丰富**：可推出许多有助于了解现象的结论。
3. **可以印证或否证**：任何人都无法印证又无法否认的，科学家视为无用（生物学的"引得来希" entelechy；"你如不改过，就会入地狱被硫黄火烧"）。
4. **自相一致**。
5. **尽可能与已有的科学知识不相冲突**——"尽可能"，不是"必须死守"。已有知识不足以说明新现象时，只有开始怀疑既有知识；但它是许多人长久累积所成，更动要特别小心。"对于既有的知识累积并未登堂入室，而贸贸然提出'新说'，只是表示我们还未到达研究学问的成年。"
6. **简单**：两假设其余相等，取较简单者——**奥康之刀（Occam's Razor）**："若非必要的东西，不可增加。"

## 7. 求证

- 《韩非子·显学》："无参验而必之者，愚也；弗能必而据之者，诬也。"
- 赫胥黎：灵魂不朽之说，"我并不否认，也不承认……你若能给我同等的证据，我也可以相信。"
- **证实为什么只得盖然的真**：假设多用条件语句表达，"若假设H，则可观察到E"。看到 E 而承认 H，正是**由肯定后件而肯定前件**——不是必然可靠的（"若一切老鸦都是黑的，则中国老鸦也是黑的"；见到中国老鸦黑，不能确定一切老鸦黑）。又，证实总是由一类之部分事例的真，说全类（含未知事例）的真，即由偏谓真说全谓真，而偏谓真时全谓不必真。
- **否证为什么可以确定**：**否定后件可以否定前件**，只要一个例外就足以把假设确定地推倒（"若一切鹄都是白的，则澳洲鹄也是白的"——澳洲有黑鹄）。拉瓦锡（Lavoisier）假定"一切酸都含有氧"，后来发现盐酸不含氧而酸性反强，假设不能成立。用对待关系说：一个 O 真（有些酸不含氧），A（一切酸含氧）必假。
- **态度**：假设被证实，仍须继续小心求证，提防例外；被证明为假，便立刻放弃，绝不稍稍固执成见。"在真理之神的面前，不可依恋情感的恶魔。"
- "我们不断地假设，不断地求证，才能促使我们的经验知识进步。"
