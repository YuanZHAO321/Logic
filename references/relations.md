# 关系

可用 `scripts/relations.py "a,b b,c a,c"` 判别一组有序对的性质。

传统逻辑最显而易见的狭窄之处，是没有把**关系（relation）**的研究包含进去；德国逻辑家 Schröder 对关系作过许多研究。从纯逻辑观点推敲关系须从函数论开始，只谈"关系"一词的用法与基本性质。

## 1. 四个基本概念

| 概念 | 界说 | "作丈夫"关系之例 |
|---|---|---|
| **界域**（domain） | 使 R 与各种事物发生联系的一切事物之类 | 一切丈夫之类 |
| **逆界域**（converse domain） | R 由之而生的一切事物之类 | 一切妻子之类 |
| **范限**（field） | 界域与逆界域的逻辑和 | 一切丈夫与妻子之类 |
| **反逆**（converse） | 当 aRb 时，b 与 a 所具有的关系 | "作妻子"；"在西"是"在东"的反逆；"被称赞"是"称赞"的反逆 |

R 的反逆之界域的分子，与 R 的逆界域的分子相同。

## 2. 九种性质（三类，各有正、反、准）

| 类 | 正 | 反 | 准（中间） |
|---|---|---|---|
| **自反性** | 自反：aRa 对范限每一分子为真（相似：任何人与自己相似） | 不自反：aRa 对每一分子为假（异于、作儿子、作父亲；**类的分子关系**） | 准自反：有些真有些假（欣赏、自傲——有人自我欣赏） |
| **对称性** | 对称：aRb 则 bRa（夫妇、对面、同年、相像） | 反对称：aRb 则必非 bRa（作祖先、较富、较高、在右） | 准对称：aRb 则 bRa 或非 bRa（作朋友、爱、弟兄） |
| **传达性** | 传达：aRb 且 bRc 则 aRc（大于、包含、矮于） | 反传达：aRb 且 bRc 则必非 aRc（作父亲、……的母亲、……的师傅） | 准传达：aRb 且 bRc 则 aRc 或非 aRc（朋友、喜欢） |

要点：
- 这里的"自反"不是"吾日三省"的道德自反，也不是 reflective thinking，而是一种纯粹的关系：aRa。
- **类的分子关系是不自反的**；若说一个类是它自己的分子，便引起严重的自相矛盾（诡论，见 language.md）。
- **"弟兄"不对称**：苏辙是苏轼的弟兄，苏轼也是苏辙的兄弟；但苏轼是苏小妹的弟兄，苏小妹却不是苏轼的"兄弟"。"逻辑界域里有什么大概可言？"
- **准对称不是反对称，准传达不是反传达**，不可混为一谈。"我的朋友胡适之"，胡适之也许还不认得他。
- "朋友的朋友是朋友"不见得是真话：朋友关系只是可能有传达性，不必然有。
- （补充）"反对称"相当于今日所谓 *asymmetric*；今日教科书另有 *antisymmetric*（aRb 且 bRa 则 a=b，如"小于或等于"），二者不同。

## 3. 性质的组合

| 组合 | 例 |
|---|---|
| 自反 + 对称 + 传达 | **等于**：A=A；A=B 则 B=A；A=B 且 B=C 则 A=C |
| 对称 + 传达 | **同时**（同时到达、同时上船） |
| 对称 + 反传达 | 一排士兵站在直线上的**紧靠**关系 |
| 传达 + 反对称 | **早些**、**兄长**、美些、在右 |
| 反对称 + 反传达 | **作祖父**、作父亲、作儿子 |

## 4. 项数与对应

- **项数**（从外范着想）：二项（罗米欧爱朱丽叶）、三项（结婚时作介绍人：介绍人、男方、女方）、四项、五项……多项。
- **对应**：
  - 一对一：基督教规定下的夫妇关系；
  - 一对多：作司令官（一个司令官，兵很多）；一位小姐同时交几个男友时她对男友的关系；
  - 多对一：听众之于讲演者；臣仆之于专制君王；
  - 多对多：作教员（学校中教员与学生都很多）。
- "你在与某小姐交朋友时，别生出误会，以为是一对一的关系哩！"

## 5. 关系推论的检查要点（应用）

1. 先认清论证所依赖的是关系的哪一性质（对称？传达？）。
2. 再问该关系在一切情形之下是否真有此性质；若只是"准"的，则推论无效。举一个反例即可（苏小妹、胡适之）。
3. 有效的关系推论（如"a 大于 b，b 大于 c，所以 a 大于 c"）严格说依赖一个隐伏前题——"大于"是传达的；必要时把它明白写出。
4. 用有限实例（脚本）只能显示那一组对的情形；逻辑上的性质要顾及一切可能。
